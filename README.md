# Quiz Application with Score Tracking (Python)

A menu-driven console quiz program built with plain Python 3 (no external libraries).

## Features
- Multiple-choice questions with instant feedback (correct answer shown on mistakes)
- Input validation: only options 1 to 4 are accepted
- Score, percentage and grade (Excellent / Good / Needs Practice)
- Every result saved to `scores.txt` (name, score, total, date)
- View the top 5 high scores from the menu

## Requirements
- Python 3.8 or above

## Run
```bash
python quiz.py
```

## Menu
1. Start Quiz
2. View High Scores
3. Exit

## Grading
| Percentage | Grade |
|---|---|
| 80% or more | Excellent |
| 50% to 79.9% | Good |
| Below 50% | Needs Practice |

## Files
- `quiz.py` : the full program
- `scores.txt` : created automatically after the first quiz (not tracked in git)
